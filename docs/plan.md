# Current scope

Keep this a small personal practice companion. No further feature expansion is required.

1. Recommend a complete untouched Codeforces round, preferring recent Div. 2, then Div. 3, then Div. 4. Offer up to three choices automatically. Keep the original lineup and duration.
2. Generate a balanced five-problem custom contest when requested or when a suitable full round is unavailable. Keep source links and source-aware submission tracking.
3. Let the user compete directly on CF or use a local scheduled timer. Save schedules, deadlines, results and history in the browser.
4. Show solves, attempts, and solve times so the user can review each session. Approximate performance is available where an original rated comparison field exists.
5. VC estimate starts at the latest official CF rating. Only eligible native virtuals started after that official result adjust it. Every new official rated result resets it, even if the official rating is unchanged. Custom/local sessions remain practice results.
6. History refresh discovers and imports current-period virtuals automatically. No separate rated registration, ranked-mode toggle, or second lifetime rating is needed.

Keep the existing HTML/JavaScript modules and small standings proxy. Preserve earlier familiarity checks, source IDs, original timing, and cached results on failures. Simplify the user flow and fix core defects before considering any new capabilities.
